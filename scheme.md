📝 Примечание

Каталог **templates/** содержит HTML-шаблоны для отображения страниц приложения (Flask + Jinja2). Без этой папки приложение выдаёт ошибку `TemplateNotFound`.

Каталог **venv/** содержит виртуальное окружение Python с установленными зависимостями проекта (библиотеки, служебные файлы и конфигурации). 
В связи с большим количеством вложенных файлов и директорий его внутренняя структура в данной схеме не приводится.
